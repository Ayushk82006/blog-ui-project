# 🌐 Ayush Blog (HTML & CSS Practice Project)

This is a simple blog website I built while learning **HTML and CSS**.
The goal of this project is to improve my understanding of layout, design, and responsive UI.

---

## 🚀 Features

* 🧭 Sticky Navigation Bar with scroll effect
* 🎯 Hero Section (intro + call-to-action button)
* 📰 Blog Cards Layout (Grid + Flexbox)
* 📌 Sidebar (Search, Categories, Recent Posts)
* 🎨 Dark Theme UI
* ✨ Hover Effects (cards + buttons)
* 📱 Responsive Design (mobile-friendly)
* 🔗 Social Media Footer

---

## 🛠️ Tech Used

* HTML5
* CSS3 (Flexbox + Grid)
* Google Fonts
* Font Awesome Icons
